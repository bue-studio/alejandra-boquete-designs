# Alejandra Boquete Designs

Maqueta visual e interactiva del home, versión 8.

Sitio: https://bue-studio.github.io/alejandra-boquete-designs/

## Actualizaciones

Reemplazar `index.html` por la nueva versión y subir el cambio a la rama `main`. GitHub Pages publica los cambios automáticamente en el mismo enlace.

El HTML contiene sus estilos y código; las imágenes y fuentes se cargan desde servicios externos. Es una maqueta de presentación: las interacciones del carrito y la suscripción son demostrativas.
